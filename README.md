# My Switcher

Локальный прототип автокоррекции раскладки клавиатуры для Windows 10/11 (RU/UA/EN).

## Скачать EXE

1. Открой вкладку **Actions**: https://github.com/Klasters18/ChatGpt/actions
2. Выбери workflow **Build My Switcher for Windows**.
3. Нажми **Run workflow** → **Run workflow**.
4. Дождись зелёной галочки завершения сборки.
5. Открой запуск workflow и скачай артефакт **MySwitcher-Windows-x64** внизу страницы в разделе Artifacts.
6. Распакуй архив — внутри будет `MySwitcher.exe`.

## Сборка локально на Windows

Установи Python 3.11+, затем запусти `build_windows.bat`. EXE появится в `dist\MySwitcher.exe`.

## Важно

Это ранний MVP, не полноценная замена Punto Switcher. Исправление слов выполняется после пробела и только при единственном точном совпадении в небольшом локальном словаре. Обработка клавиатуры пока не протестирована на разных приложениях Windows. Проверь работу вручную перед включением автозапуска. Системный трей и глобальная горячая клавиша отмены в текущей версии не завершены.
